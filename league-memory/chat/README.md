# Chat drop

The league's group chat lives on the company Slack, which the routine can't
(and shouldn't) read. Instead, before Wednesday's run, paste the good stuff
into `week-N.md` (N = the week whose games just finished), one line each:

    - Matt: "its called strategy" (reply to the Mattress Fund roast)
    - Sam: "Drake Maye didn't throw an Interception"
    - Peter circled Riley's benched Pitts in green: "Oh wait..."

Quotes are used word for word. Screenshots work too: drop them in
`league-memory/issues/img/` and mention them here. The routine reads this file
alongside `storylines.json`.
